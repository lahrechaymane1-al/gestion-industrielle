Optional hero background
=======================

Place an industrial / neon abstract image here as:

  bg-industrial.png

The home dashboard hero (`HomeDashboardPage.tsx`) loads this URL as a subtle
full-bleed layer under gradients and glass overlays for readability.

Optionally, you can also add the same URL as a top layer in
`AppAmbientBackground.tsx` — keep opacity low so contrast stays accessible.

Use moderate resolution (e.g. 1920px wide, compressed) for performance.
